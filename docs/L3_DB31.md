# L3 DB31: qwen window importer, one parse per line and the selected text written into the wire (D-DB23-1, D-DB23-2)

Brief: close or move D-DB23-1 (double frame and parse per line) and D-DB23-2 (last copy of the selected text,
`turns::finish2` -> `col.text` -> wire) (docs/L3_RESTRUCTURE_SPEC.md 7.5). Byte-identical output, no compiler
edits, lane `bench/l3/qwen/` and add-only `bench/l3/pkgs/turns/turns.pruv`. Base: main 324551ae.

## What landed

- `bench/l3/qwen/chain.pruv`: `scan` / `select` are split into a per-line `note(inout index: Index, doc, ordinal)`
  and a final `resolve(index, inout marks) -> Chain { active, cut, bad }`. The chain facts per line (uuid,
  parentUuid, role check, leaf candidate, bad flags) are the ones `scan` took; `resolve` computes the marks as
  `select` did. `chain` no longer frames or parses.
- `bench/l3/qwen/import.pruv`: `window_wire` frames and parses each line once (`framing::window_next` then
  `entry::parse_line_span`). Object lines go to `chain::note` and to an event log; Dropped lines store only the
  `text::dropped_user` result. The log is a struct `Events { records: [u8], used, text: [u8], end }` with 9-byte
  records (kind, two u32 fields) and decoded text in a separate growable `[u8]`. After the loop `chain::resolve`
  selects, and `replay` drives `turns` from the log in frame order exactly as the old second pass did (title =
  last Ranked line, selected = `!chain.active || selected[ordinal] == 1`, pending / started / skip_user, model =
  last non-empty model of a selected line). `consume_entry`, `answer_blocks` and `wfail_at` are gone.
  The failure codes and positions are unchanged: a parse defect is `wfail_zero` (the old `scan` saw it first),
  a title defect is `wfail_zero`, a consume defect on a selected line is `wire_fail(internal_invariant, start)`.
  Log buffers start at `len(data) / 4` and grow by `need + need / 4 + 65536` (RSS, see Perf).
- `bench/l3/pkgs/turns/turns.pruv` (add only, no existing item changed):
  `pub struct Layout { kept, total, text_len }`, `pub fn text_layout(st, sl) -> Layout`,
  `pub struct Placed { turns: [i64], kept, trimmed, total, text_len, ok: bool }` and
  `pub fn finish_into(st, sl, bk: Store, base, inout wire: [u8], at) -> Placed`, which does what `finish2` does
  but copies each kept draft into `wire` at `at + lo` (turn refs stay `base + lo`). `window_wire` sizes the wire
  as `hl + base + text_len` from `text_layout`, writes the text with `finish_into` and fails with `wfail_zero`
  when `ok` is false or `kept` / `text_len` differ from the layout. `col.text` and the last `copy_span` are gone.
