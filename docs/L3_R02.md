## 4. Gaps (language/compiler)

| Id | Gap | Where | Workaround |
|---|---|---|---|
| G-R02-1 | A `take` array parameter moved into a struct field is rejected by the LLVM backend with `codegen/unsupported_type`. Minimal case: `struct D { a: [i64] }` and `fn wrap(take a: [i64]) -> D { return D { a: move a }; }`. | `ent_state.pruv:178` `ctx_new(blob, lg)` | `blob` and `lg` are still copied into `Ctx` on every begin/step. Only arrays made inside the function are moved. |

## 5. Debt

| Id | Cell | Cause (line level) |
|---|---|---|
| D-R02-1 | RSS M 3.017x, L 3.593x | The wire stores every text as one `i64` word per UTF-16 unit (`host.rs:89` `encode_utf16`, `host.rs:242` `pool: Vec<i64>`, `host.rs:282` `mk_packet`), so the L input is 438,723 words (3.5 MB) where hand holds the JSON as bytes. The state section carries that blob again in `prev`, and `ent_state.pruv:193` copies `blob` and `lg` into `Ctx` (G-R02-1), so the same text lives in up to three `[i64]` copies at the step. Fix: a `[u8]` UTF-8 pool with spans (`load_le`/`store_le`, `str_from_utf8`), which changes the `entry_begin`/`entry_step` packet and the `req` consumer. Minor: `ent_bound.pruv:241` now allocates the id buffer at `3 * ns` words even when no session needs the predicate (up to 13.4 MB at the `ns` clamp); grow it on the first id instead. |
| D-R02-2 | time M 1.850x, L 1.920x | At the step, `entry_api.pruv:57` calls `state_ok`, which re-runs `input_check` on the stored blob (`ent_state.pruv:167`, `ent_packet.pruv:330`) and `log_ok` over every stored completion (`ent_state.pruv:169`). Then `ctx_new` copies the blob and `run_item` replays op 9 from `pos = 0`. All of this is linear in the input, and the hand side does none of it. Fix: B, a resident owned progress root, so the step trusts state checked once at begin. |
| D-R02-3 | scope | B (one owned progress root) and C (completion/effect handoff by source spans) are not done. The wire still replays from the start on each step. Removing replay needs a trusted resident state that still rejects forged state (`forge_test.py` covers op 1 and op 6). The at-most-once effect and continuation tests were not extended past the existing entry/req suites. |
