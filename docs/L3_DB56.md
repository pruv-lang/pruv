# L3 DB56: one-copy grok rpc lines and owned jstr decodes (G-DB55-5, G-LG33-1, G-LG33-7)

Brief: (1) G-DB55-5, grok rpc trims to bounds and copies at most once before `lines::parse_owned`. (2) G-LG33-1, a
jstr decode that builds an owned `[u8]` and moves it into `str_from_utf8`; old functions and signatures stay; switch
grok, mcp, opencode and claude where it drops a copy (grok and opencode switched; mcp has none; claude blocked,
G-DB56-2); codex is not switched (G-DB56-1). (3) G-LG33-7, run the grok
`acp-` fixtures at load below 5. Base: main f7dd7978. One release `pruvc-rs` build from this base; no compiler or
runtime change.

## What landed

- `pkgs/jstr/jstr.pruv`: new `string_text_owned`, `string_text_scanned_owned`, `string_text_plain_owned` (same
  `requires` / `ensures` as `string_text`, `string_text_scanned`, `string_text_plain`) and `owned_text(take data: [u8])
  -> str` (`adapter_probe` for a buffer the caller gives up). Each decodes into a fresh local, tests it with
  `utf8_valid` at run time and binds `let text: str = str_from_utf8(bytes);` at the buffer's last use, so the block
  moves into the str (LG33). The old functions are unchanged.
- `pkgs/access/access.pruv`: new `string_text_owned(doc, id)` and `string_text_scanned_owned(doc, id)`, the bodies
  of `string_text` / `string_text_scanned` (same contracts, same plain-mark split) on the owned decodes.
- grok `rpc.pruv`: `trim_bytes` (a second copy of the line) becomes `trim_bounds(b) -> Bounds { lo, hi }` with
  `ensures 0 <= lo <= hi <= len(b)`; `parse_line` trims `subview(line, 0, n)` to bounds, copies `line[lo..hi)` once with
  `copy_range` and moves it into `lines::parse_owned`. The error detail goes through `owned_text(move dt)`.
- Switched callers (Claude sonnet write delegation, reviewed and kept as is):
  grok `util::cfg_str`, `util::long_str`, `entry::feed_user` (`owned_text`), `util::str_at`
  (`access::string_text_scanned_owned`); opencode `entry::iso_str`, `rows::clean_title`, `rows::updated_number`,
  `util::cfg_str` (`owned_text`), `util::str_at` (`access::string_text_owned`).
- claude is not switched: its `access.pruv` and `jstr.pruv` are links to `bench/l3/lib/`, not `pkgs/`, so the five
  sites the delegation switched (`entry::string_field_of`, `entry::string_content`, `import::consume_entry_of`,
  `import::read_window` model id, `time::iso_of`) failed `unknown_fn` in claude a1, a2, a4 and were reverted (G-DB56-2).
  claude sources are byte-identical to main.
- Not switched: callers that read a parameter or a field (grok `path`, `copy`, `read:161`, `entry:89`; opencode `path`;
  claude `import:309`) and grok `read:67`, which reads `enc` again after the decode; they keep `adapter_probe`. mcp has no
  decode that drops a copy (its strings are compared in place), so mcp is unchanged. qwen, json and supervisor are
  unchanged.

## Decisions

| id | decision | why | status |
|---|---|---|---|
| D-DB56-1 | grok rpc trims to bounds on the caller's line and copies `line[lo..hi)` once into the buffer it moves into `parse_owned` | the old path copied `line[0..n)` and `trim_bytes` copied again; `parse_owned` needs an owned buffer from 0, so one copy stays | kept |
| D-DB56-2 | owned decodes test `utf8_valid` at run time and keep the result values of the old functions | the old `utf8_to_string` adapter returns "" for invalid UTF-8, so `len(owned) != len(bytes)` (old) and `!utf8_valid` (new) pick the same `InternalInvariant`, and `owned_text` returns "" where `adapter_probe` did | kept |
| D-DB56-3 | bind `let text: str = str_from_utf8(b);` and return `move text` instead of returning the call | `str_from_utf8(b)` as a return value or constructor argument is copied (`pruv_copy_v2` + free) on LLVM; passing the str local without `move` is `array_alias` | kept |
| D-DB56-4 | `owned_text` has no `ensures` on the result length | `old(data)` is not allowed on a `take` parameter (`old_argument`); every caller checks the length itself | kept |
| D-DB56-6 | the audit's must-fix (double UTF-8 check under `--no-verify`) is recorded as G-DB56-3, not fixed in Pruv source | every test and perf build is verified mode, where the check is not doubled; dropping `utf8_valid` breaks verification; the fix is a compiler lowering, out of lane | kept |
| D-DB56-5 | only callers whose decode buffer is a fresh local at its last use are switched | a parameter, a field or a buffer read again after the decode cannot be moved; switching those would add a copy | kept |
